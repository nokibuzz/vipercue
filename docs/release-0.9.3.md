## Claude API provider

ViperCue now offers **CLAUDE API** alongside Offline, Codex, and OpenAI API for Live interview answers and ASMA Feedbacker recaps. Enter your own Anthropic Console API key, test access to Claude Haiku, then start the session. Answers stream into the overlay, and local history records actual token counts, model, and timing. Switching API providers clears the key field to prevent using one provider's key with another.

Claude API usage is billed separately from a Claude.ai subscription. ViperCue does not use Claude subscription credentials or require the Claude Code CLI. See the [Claude connection guide](https://github.com/nokibuzz/vipercue/blob/main/docs/claude-connection.md).

The Intel (`x64`) and Apple Silicon (`arm64`) DMGs remain ad-hoc signed and **not notarized**. Follow the [macOS installation guide](https://github.com/nokibuzz/vipercue/blob/main/docs/macos-install.md) for the standard Gatekeeper warning.
